Booklet setup help

1. Choose your PDF. Select or drag in a PDF file.

2. Set up your booklet. Choose physical sheet size, finished page size, orientation, binding direction, scaling, gutter, and margins.

3. Generate and review. Check both front and back sides for a few sheets. Booklets need page counts divisible by four; AutoBook adds blank pages when required.

Print tips: Print double-sided at Actual Size / 100%. Test a few pages first and verify the printer's duplex flip-edge setting. Select the correct paper size in the print dialog.

Keyboard shortcuts

Ctrl/⌘ + Z — Undo settings

Ctrl/⌘ + Y — Redo settings

Esc — Close help

Undo/Redo applies to booklet setup settings. Uploaded files and generated PDFs are not part of the history.
