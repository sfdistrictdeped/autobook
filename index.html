About AutoBook

Booklet setup help

1. Choose your PDF. Select or drag in a PDF file.

2. Set up your booklet. Choose physical sheet size, finished page size, orientation, binding direction, scaling, gutter, and margins.

3. Add page numbering and borders. Optional page numbers and decorative borders are applied before booklet generation.

4. Preview and export. Check both front and back sides for a few sheets. Booklets need page counts divisible by four; AutoBook adds blank pages when required.

Print tips: Print double-sided at Actual Size / 100%. Test a few pages first and verify the printer's duplex flip-edge setting. Select the correct paper size in the print dialog.

Page selection: In Booklet Settings, enter “all” or ranges such as 1-3, 5, 8-10. You can also insert blank pages after selected source pages.

Remembered preferences: Your setup preferences are saved locally in this browser and can be reset with Reset Settings.

Print Test Sheet: Use the test sheet to verify scale, orientation, margins, and duplex direction before printing a full booklet.

Keyboard shortcuts

Ctrl/⌘ + Z — Undo settings

Ctrl/⌘ + Y — Redo settings

Esc — Close help

Undo/Redo applies to booklet setup settings. Uploaded files and generated PDFs are not part of the history.
